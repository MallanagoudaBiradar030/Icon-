# Shadow Sketch Icons

A custom Android icon concept for a black / silver anime wallpaper: imperfect white sketch lines with small red accents.

## Build an APK from your phone
1. Open the **Actions** tab in this repository.
2. Select **Build Shadow Sketch Icons APK**.
3. Tap **Run workflow** (or wait for the push-triggered build).
4. Open the completed run and download the `shadow-sketch-icons-apk` artifact.
5. Extract the artifact ZIP and install the APK on your Android phone.

## Safety
- The app requests no Android permissions.
- It has no internet permission, analytics, advertising, or tracking code.
- It does not modify the wallpaper, system settings, or user files.
- You can uninstall it normally.

## Current status and compatibility
The project includes a preview screen, custom vector sketch resources, appfilter metadata, and a cloud build workflow. The appfilter metadata follows a common launcher icon-pack convention, but Niagara compatibility is not yet confirmed on a physical device. If Niagara does not show the pack in its icon-pack selector, this build may only work as a preview app until the launcher-specific integration is adjusted.

This APK is a debug build generated by GitHub Actions, not a Play Store release.
